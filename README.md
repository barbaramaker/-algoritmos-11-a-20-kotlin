# Algoritmos 11 a 20 — Kotlin

## **Sobre o projeto**

Este repositório contém a resolução dos algoritmos 11 a 20 do livro Introdução à Programação: 500 Algoritmos Resolvidos, de Anita Lopes e Guto Garcia, convertidos para a linguagem Kotlin.

A atividade tem como objetivo praticar os conceitos básicos de programação, trabalhando com comandos de saída, variáveis, operações matemáticas e manipulação de strings.

Durante o desenvolvimento, procurei manter a lógica dos algoritmos originais, adaptando os comandos para a sintaxe do Kotlin. Também realizei testes para verificar o funcionamento de cada programa e fiz alguns ajustes quando necessário.

Todos os exercícios foram desenvolvidos e executados no IntelliJ IDEA.

## Tecnologias utilizadas

* Kotlin: linguagem utilizada para desenvolver os algoritmos.
* IntelliJ IDEA: ambiente utilizado para escrever e executar os códigos.
* JDK (Java Development Kit): necessário para executar os programas Kotlin na JVM.
* Git e GitHub: utilizados para organizar e armazenar os exercícios.

## Descrição dos algoritmos

**Algoritmo 11 — Primeira mensagem**

Neste primeiro algoritmo, utilizei o println() para mostrar uma mensagem no console. Foi um exercício simples, mas importante para começar a entender como funciona a saída de dados em Kotlin.

**Algoritmo 12 — Mensagens na mesma linha**

Aqui aprendi a utilizar o print() para mostrar duas mensagens na mesma linha. Também adicionei um espaço entre elas para deixar o resultado mais organizado.

**Algoritmo 13 — Quebra de linha**

Neste exercício, utilizei o \n para fazer a segunda mensagem aparecer na linha de baixo. Foi uma forma de entender melhor como organizar a saída do programa.

**Algoritmo 14 — Outra forma de quebrar a linha**

Esse algoritmo foi parecido com o anterior. A diferença é que coloquei o \n no final da primeira mensagem, conseguindo o mesmo resultado.

**Algoritmo 15 — Organizando mensagens**

Aqui trabalhei com várias quebras de linha dentro de um único print(). Aprendi que posso utilizar \n\n para deixar uma linha em branco e organizar melhor o texto exibido.

**Algoritmo 16 — Variáveis**

Neste algoritmo, comecei a trabalhar com variáveis. Declarei uma variável do tipo Int, atribuí o valor 10 e depois mostrei esse valor no console.

**Algoritmo 17 — Exibindo variáveis com texto**

Aprendi a utilizar o $ para mostrar o valor de uma variável dentro de uma mensagem. Isso deixou o código mais simples e fácil de entender.

**Algoritmo 18 — Cálculos com variáveis**

Neste exercício, realizei uma soma utilizando o valor de uma variável. O mais importante foi entender que mostrar o resultado de x + 1 não altera o valor original de x.

**Algoritmo 19 — Funções matemáticas**

Esse foi um dos algoritmos mais complicados até agora, principalmente por apresentar várias funções matemáticas que eu ainda não conhecia.

Precisei trabalhar com raiz quadrada, potenciação, logaritmos, seno, valor absoluto e conversões numéricas.

Uma das maiores dificuldades foi entender por que alguns cálculos apresentavam resultados como 7.999999999999998 em vez de 8. Também precisei fazer ajustes na conversão de números para inteiros, utilizando roundToInt().

Apesar de ter sido mais trabalhoso, esse exercício me ajudou a entender melhor como o Kotlin realiza operações matemáticas e como pequenas diferenças de precisão podem afetar os resultados.

**Algoritmo 20 — Manipulação de strings**

Esse também foi um dos exercícios mais trabalhosos, porque reuniu várias operações com textos em um único programa.

Aprendi a utilizar funções como length, firstOrNull(), lastOrNull(), drop(), take() e takeLast() para trabalhar com diferentes partes de uma palavra.

Também precisei entender como funcionam os índices dos caracteres, já que em Kotlin a contagem começa em zero.

Uma parte interessante foi testar o programa com palavras diferentes, incluindo palavras pequenas, para verificar se tudo continuava funcionando corretamente.

No final, consegui compreender melhor como manipular strings e como utilizar essas funções para evitar erros durante a execução.
